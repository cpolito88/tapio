# tapio

A Pekko-inspired actor toolkit for Python. Typed, asyncio-native actors with
supervision — Pydantic models throughout.

!!! warning "Pre-alpha"

    Scaffolding only — the runtime is not implemented yet. These pages fill in
    as it lands: getting started, actor lifecycle, supervision, testing, and
    the blocking-code warning page.

Every code block on this site is a snippet include from `examples/`, so nothing
documented here is unexecuted.
